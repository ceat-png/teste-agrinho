# 🌱 Agro Forte, Futuro Sustentável

## 📌 Sobre o Projeto

Este site foi desenvolvido como projeto para o tema **"Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente"**. O objetivo é conscientizar e engajar o público sobre práticas agrícolas sustentáveis que conciliam alta produtividade com preservação ambiental.

## 🎯 Objetivo do Tema Agrinho

Demonstrar como a agricultura moderna pode ser forte e produtiva sem agredir o meio ambiente, através de tecnologias como plantio direto, integração lavoura-pecuária-floresta (ILPF), uso racional da água e energias renováveis. O projeto incentiva o usuário a calcular seu impacto positivo e participar simbolicamente do reflorestamento.

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica do site
- **CSS3** - Estilização, responsividade (Media Queries) e efeitos visuais (hover, transições)
- **JavaScript (Vanilla)** - Manipulação do DOM, interatividade, modo escuro, cálculos e contador
